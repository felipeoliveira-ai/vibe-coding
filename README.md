## Comece por aqui

1. Ache, na lista abaixo, o vídeo que você viu.
2. Toque em **Abrir o passo a passo**.
3. Siga o guia de cima para baixo.

Você não precisa criar conta no GitHub para ler nem para copiar nada.

Nunca usou o Claude Code? Comece pela página [Claude Code](claude-code/): o que é, como baixar com um clique e as
palavras que aparecem nos guias. Leva 5 minutos.

Quer só as skills? Estão todas em [Skills que eu uso](skills/), com o comando de cada uma.
