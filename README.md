# Vibe Coding

Aqui ficam os passo a passos dos vídeos do [@felipeoliveira.ai](https://www.instagram.com/felipeoliveira.ai/).
Tudo em português, com o que instalar, os comandos e o que eu medi de verdade.

## Comece por aqui

1. Ache, na lista abaixo, o vídeo que você viu.
2. Toque no nome da pasta, na coluna **Passo a passo**.
3. Siga o guia de cima para baixo.

Você não precisa criar conta no GitHub para ler nem para copiar nada.

Nunca usou o Claude Code ou o terminal? Leia antes os [Primeiros passos](primeiros-passos/). Leva 5 minutos.

## O que é cada coisa nesta página

| Você vê | O que é |
|---|---|
| Pastas com nome de vídeo | O passo a passo de cada vídeo. É o que você procura. |
| `primeiros-passos` | O básico para quem nunca usou o Claude Code ou o terminal. |
| `skills` | Arquivos que o Claude lê quando você instala uma skill. Você não precisa abrir. |
| `LICENSE` | A licença. Pode usar e copiar à vontade. |
| `README.md` | Esta página. |
