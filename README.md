## Skills deste kit

Ficam na pasta [`skills/`](skills/). Para instalar uma no Claude Code (precisa do Node):

```bash
npx skills add felipeoliveira-ai/kit-ia --skill medir-mcp
```

Antes de instalar qualquer skill, leia o que ela faz. Ela passa a ter influência sobre o que o seu agente faz.
