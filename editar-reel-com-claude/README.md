# Editar Reel com o Claude

Do Reel: https://www.instagram.com/reel/DfVfO6uhPdV/ · [Voltar ao início](../README.md) · Primeira vez? [Primeiros passos](../primeiros-passos/)

Você precisa de 3 coisas.

## 1. Whisper

Transcreve a sua fala palavra por palavra, com o tempo de cada uma.

https://github.com/openai/whisper

## 2. HyperFrames

O Claude escreve os gráficos e monta o vídeo no seu computador.

https://github.com/heygen-com/hyperframes

No terminal (ou peça para o Claude rodar):

```bash
npx skills add heygen-com/hyperframes
```

## 3. A sua skill de edição

Depois de 2 ou 3 vídeos, peça para o Claude:

> Lê os arquivos dos meus últimos Reels e escreve a minha skill de edição: fontes, cores, legenda e o passo a passo.

Daí em diante, todo Reel novo já nasce no seu padrão.

Bons vídeos!
